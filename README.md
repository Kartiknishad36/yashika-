## Setup

```bash
git clone https://github.com/Kartiknishad36/yashika-.git
cd yashika-
pip install -r requirements.txt
cp .env.example .env
# edit .env
python3 main.py
```

**Required env:** `API_ID` `API_HASH` `STRING_SESSION` `OWNER_ID`  
**Optional:** `ASSISTANT_SESSION` `COOKIES_PATH` `LOG_GROUP_ID`

> Put `cookies.txt` in project root for YouTube. Install `ffmpeg` on server.
