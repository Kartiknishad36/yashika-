## ⚙️ Quick Setup

```bash
git clone https://github.com/Kartiknishad36/yashika-.git
cd yashika-
pip install -r requirements.txt
cp .env.example .env
# .env edit karo
python3 main.py
```

### Required ENV

| Variable | Description |
|:---|:---|
| `API_ID` | my.telegram.org |
| `API_HASH` | my.telegram.org |
| `STRING_SESSION` | Pyrogram session string |
| `OWNER_ID` | Tumhara Telegram user ID |

### Optional ENV

| Variable | Description |
|:---|:---|
| `ASSISTANT_SESSION` | 2nd account for VC |
| `LOG_GROUP_ID` | Log group |
| `COOKIES_PATH` | `cookies.txt` (YouTube) |
| `SUPPORT_CHAT` | Support invite link |
| `UPDATE_CHANNEL` | Channel link |
| `OWNER_USERNAME` | Owner username |

> **Tip:** Server pe `ffmpeg` install rakho. Music ke liye root me `cookies.txt` rakho.
